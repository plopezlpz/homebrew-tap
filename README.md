# homebrew-tap

Homebrew tap for [paddock](https://github.com/plopezlpz/paddock), a tmux popup for jumping between sessions,
windows and panes that also shows which AI coding agents are working, waiting or finished.

```sh
brew install plopezlpz/tap/paddock
```

Then follow the [Homebrew install steps](https://github.com/plopezlpz/paddock#with-homebrew): a few lines in your
tmux config load paddock, and agent-status.tmux adds the agent state.

`Formula/paddock.rb` is generated by paddock's release workflow from the release's checksums; don't edit it by hand.
